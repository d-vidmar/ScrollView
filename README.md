# Mobilna aplikacija Scroll View
Pri šolski nalogi sem v Android Studiu izdelal mobilno aplikacijo *Scroll View*. Namen izdelave te aplikacije je uporaba gradnika *ScrollView*, ki vsebuje *LinearLayout*, v katerem sta dva stolpca za podnaslov in besedilo, na koncu pa je še gumb za komentiranje. Ob kliku na gumb se prikaže *Toast* s sporočilom "comment sumbitted!".
